# 🗺️ Mapbox Directions App

A simple **Mapbox Directions App** built with **Next.js**, **React**, and **Mapbox GL JS**, styled using **Tailwind CSS**. It provides real-time directions, route distance, and duration calculation with an interactive, responsive map interface. Optimized for performance and ease of use.

## 🚀 Features
- 📍 **Real-time Directions:** Get step-by-step navigation.
- 🌍 **Interactive Map:** Smooth map interactions powered by Mapbox GL JS.
- 🎯 **Customizable UI:** Clean and responsive design with Tailwind CSS.
- 🧭 **Distance & Duration Calculation:** Accurate route data.

## 🛠️ Tech Stack
- **Next.js** for server-side rendering and routing.
- **React** for building dynamic UI components.
- **Mapbox GL JS** for seamless map rendering.
- **Tailwind CSS** for modern, responsive styling.

## 📦 Installation

```bash
git clone https://github.com/yourusername/mapbox-directions-app.git
cd mapbox-directions-app
npm install
npm run dev
```
